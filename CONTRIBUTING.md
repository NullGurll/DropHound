# Contributing to DropHound

DropHound welcomes focused bug fixes, accessibility improvements, packaging
updates, and interface enhancements.

1. Fork the repository and create a branch.
2. Use Python 3.12 and install `requirements-dev.txt`.
3. Run `python -m unittest discover -s tests -v`.
4. Test changes on every operating system they affect.
5. Open a pull request describing the user-visible behavior and verification.

Do not include downloaded content, account cookies, credentials, or private
links in issues, tests, screenshots, or pull requests.
