# Security

Please do not publish security vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting feature for the DropHound
repository. Include the affected version, operating system, reproduction steps,
and impact. Never attach real cookies, credentials, or private download URLs.

DropHound launches the bundled Cyberdrop-DL engine locally. It does not operate
a hosted download service or transmit telemetry to a DropHound server.
